# ハシバミ製作所 ブランドガイド(第3版)

> **この文書は架空の組織の架空のブランドガイドである。** SmAIltalk の V3-M6(既存資産の
> 取り込み)を実地で確かめるために書いた**テスト用の資産**であり、実在の企業・団体・製品と
> 一切関係が無い。名前・色・書体の選択に実在のブランドを模した意図は無い。

ハシバミ製作所は、木工の受注生産をしている小さな工房である。工房の見た目は「**木陰の落ち着き**」を
基調とし、紙の見積書からそのまま画面へ移ってきたような静けさを保つ。

---

## 1. 配色

### 1.1 地色と面

| 使いどころ | 指定 | 補足 |
|---|---|---|
| ページ全体の地色 | `#fffdf8` | 白ではなく、わずかに温かみのある紙色。工房の見積用紙の色から取った |
| 強調された面(表の見出し・カーソルが乗った行) | `#eef2ea` | 木陰の淡い緑。地色との差はごく浅くする |

### 1.2 文字色

| 使いどころ | 指定 | 補足 |
|---|---|---|
| 本文 | `#14281d` | 深い緑黒。真っ黒は使わない |
| 補助的な説明文 | `#405146` | 本文よりひとつ淡い緑 |
| 項目名(ラベル) | `#33443a` | 本文と補助文の中間。項目名は読み飛ばされないだけの濃さを保つ |
| 未入力時の案内文 | `#4d5e53` | いちばん淡いが、灰色まで抜かない |
| エラー・危険な操作 | `#8c1d18` | 錆の赤。彩度を上げすぎない |

### 1.3 線とフォーカス

| 使いどころ | 指定 | 補足 |
|---|---|---|
| 区切り線・枠線の色 | `#6b7a70` | 鉛筆で引いた罫線の濃さ |
| 枠線の太さ | `1px` | 太らせない |
| 枠線の線種 | `solid` | 破線・点線は使わない |
| キーボード操作中の強調(フォーカスリング)の色 | `#1a5fb4` | 配色の中で唯一の寒色。見落とさせないため意図的に外す |
| フォーカスリングの太さ | `2px` | |
| フォーカスリングの線種 | `dashed` | 面の枠線と混ざらないよう、あえて破線にする |

## 2. 書体と行の組み

| 項目 | 指定 |
|---|---|
| 本文の書体 | `Hiragino Sans, Yu Gothic, sans-serif` |
| 本文の行間 | `1.7` |
| 補助文の文字寸 | `0.875rem` |
| 注記の文字寸 | `0.75rem` |

見出しに専用の書体は与えない。太さと余白だけで階層を作る。

---

## 3. 余白(6段の目盛り)

余白は**6段の目盛り**だけで組む。中間の値を勝手に作らない。

| 段 | 指定 | 主な使いどころ |
|---|---|---|
| 1(最小) | `0.25rem` | 文字とアイコンのあいだ |
| 2 | `0.5rem` | 入力部品の内側 |
| 3 | `0.75rem` | 表のセルの内側 |
| 4 | `1rem` | 段落と段落のあいだ |
| 5 | `1.5rem` | 節と節のあいだ |
| 6(最大) | `2.5rem` | 画面の上下の余り |

---

## 4. 面の作り

| 項目 | 指定 | 補足 |
|---|---|---|
| 入力部品の角丸 | `6px` | 角は落とすが、丸くしすぎない |
| 面の影 | `0 1px 2px #14281d1a` | 紙が1枚だけ浮いている程度。二重・三重に重ねない |

---

## 5. 画面の寸法

| 項目 | 指定 | 補足 |
|---|---|---|
| 画面全体の最大幅 | `1120px` | これより広い画面では左右に余白を残す |
| 詳細画面の項目名の欄の幅 | `9rem` | 項目名を折り返させない |
| ログイン画面の最大幅 | `24rem` | 1枚の伝票くらいの幅に収める |
