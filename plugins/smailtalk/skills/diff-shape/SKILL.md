## 1. 差分パッチの外側 —— 必ずこの3キー

```json
{
  "diff_id": "add-task-table",
  "intent": "作業の一覧を持てるようにする",
  "operations": [ { "op": "add_table", "table": { "…" : "…" } } ]
}
```

- `diff_id` / `intent` / `operations` の**3つとも必須**。1つでも欠けると差分全体が拒否される。
- `diff_id` は **59文字以内**(undo が `undo-<diff_id>` という名前を作るため)。
- `intent` は**空文字が不可**。
- `operations` は**1件以上の配列**。
- **この3つ以外のキーを外側に書けない。**

**【2026-08-25 追記】この3キーを検査するより前に、権限が見られる。**
**`apply_diff` も `dry_run_diff` も、順序は「名乗り → `app` × `write` の規則 → `intent`」である。**
**規則が無い相手には、`intent` を空にしていても `intent` の話は返らず、権限の断りが返る。**
**着手前は `dry_run_diff` だけが `intent` を先に見ていた** —— **その差は今日は無い。**
**役割の規則を1本も書いていないアプリでは、持ち主でも両方が断られる**
(直し方は `set_roles` で `owner` に `target: "app"` / `can: ["write"]` を書き戻すこと)。

- **中の5キー**:
