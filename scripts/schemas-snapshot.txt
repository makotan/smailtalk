# ## これは「永遠に変わらない」の固定ではない
#
# **その `CM-G1` 限定2 は、`ADR-0373` §Decision 2 の #6 が正面から破った。**
# `ADR-0371` が `manifest.schema.json` に名札を3箇所入れている。
# **このファイルが固定するのは「今日の姿」であって「変えてはならない」ではない。**
#
# ## 赤くなったら何をするか
#
# **このファイルを更新する前に、増えた/減ったキーが `ADR-0007` の門A を通ったかを審査すること。**
# **審査より先に更新してはならない。** 更新するだけで緑になるので、それをやると検査は
# 「動いたことに気づく」機能を失う。**機械化したのは検出であって審査ではない。**
#
# ## 数を持たない
#
# **本ファイルにも検査にも、件数のリテラルは1つも無い。** 本数はこの一覧から導く
