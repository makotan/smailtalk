#
# 列は **タブ区切り**。行の種類は5つ:
#
#   closed   <パス> <見出しの型> <spans|rowhead> <ordered|unordered> <正の集合式>
#            その節の列挙が、正の集合と**過不足なく**一致すること(両向き)。
#   allow    <パス> <見出しの型> <語> <理由>
#            その節に**意図して**置いた語彙外の語。理由を書かない行は赤になる。
#   covers   <パス> <正の集合式>
#            その集合の名前が、そのファイルのどこかに1つ残らず現れること(片向き)。
#   count    <パス> <逐語の型> <正の集合式>
#            散文に書いた**件数**が、正の件数と一致すること。
#   verbatim <パス> <正の定数名>
#            そのファイルの引用ブロックが全部その定数の**部分文字列**であること(H-G20 限定2)。
#   pair     <パス> <逐語A> <逐語B> <理由>
#            逐語A を載せたファイルには逐語B も必ず在ること(片向き。V8-M22 / J-G35)。
#            **偽になった旧文だけを切り出して配らない**ための組で、理由を書かない行は赤になる。
#
# {n} は集合の件数、{n+1} はその次の数に展開される。
# **この一覧にも検査にも数字を1文字も書かない**(H-G19 限定4 / ADR-0250 §Decision 3 の 3)。
#
# 赤くなったら、まず「正が動いたのか、skill が間違えたのか」を人が判定すること。
# **この一覧を先に書き換えてはならない。** 機械化したのは検出であって審査ではない。
